## Weekly Progress Demo

Every class, each team shows one visible improvement.

5-minute format:

1. PM: what changed.
2. Demo Driver: show one improvement.
3. QA Lead/Scribe: show evidence links.
4. Random member: explain one code area, bug, test, or doc.
5. PM: state one ask or blocker.

## Friday Weekly Sprint Packet

Required every Friday by 23:59.

Each packet must include:

- demo evidence,
- board snapshot,
- shipped work links,
- bugs and risks,
- engineering practice evidence,
- AI Use + Code Ownership Check,
- plan for next week,
- individual contribution receipts in comments.

## Stop Doing

- adding new features before testing core flow,
- saying “almost done,”
- hiding bugs,
- submitting vague screenshots,
- accepting AI code no one understands,
- making giant PRs,
- working without Issues.

## Start Doing

- test the core flow,
- write QA checklists,
- create bug Issues,
- assign owners,
- link evidence,
- update docs,
- use small PRs,
- prepare final demo reliability.
